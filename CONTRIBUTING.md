# Contributing

## Alpha contribution policy

External pull requests are not accepted for v0.1.0-alpha.

This release is published for protocol evaluation, integration development and
reproducible verification. Its public API, canonical encoding and protocol
behavior may still change, and the project is completing its source-origin
confirmation before opening code contributions.

Public bug reports and documentation suggestions may use the repository issue
tracker after the public repository exists. An issue report does not authorize
submission of private-chain configuration, credentials, validator material or
third-party source under an incompatible license.

## Security reports

Do not report a suspected vulnerability in a public issue, discussion or pull
request. Follow [SECURITY.md](SECURITY.md) and use GitHub private vulnerability
reporting after the repository owner enables that channel.

## Before external contributions open

The project will publish its contribution licensing process, code of conduct
and maintainer governance before accepting external pull requests. That policy
will define authorship requirements, review authority and the choice of DCO,
CLA or another contribution mechanism.
